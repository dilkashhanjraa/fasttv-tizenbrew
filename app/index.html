REMOTE GUIDE

Sit back. You're home.

Use arrow keys to select an app and press the remote's centre OK button to launch it. Select the ☆ on a tile to make it a favourite.

If Samsung prevents an app from opening, use the TV's regular Home screen for that app. TV app discovery needs the local FastTV service; the dashboard still works if it is unavailable.

Use Back/Return to come back to this screen. The yellow key or keyboard F toggles a focused app's favourite.
